# Deploying for free (Render + Neon)

| Part | Where | Free tier |
|---|---|---|
| Database | Neon Postgres | 0.5 GB, doesn't expire |
| API (lite mode) | Render web service | 512 MB RAM, sleeps after 15 min idle |
| Web frontend | Render web service | same |

**Lite mode** (`LITE_MODE=true`, installs `requirements-lite.txt` without PyTorch):
table tasks (classification, regression, clustering, forecasting) train on the server, on up to
10,000 rows (larger files are sampled). Text and image tasks train on the user's free Google Colab GPU through the generated notebook.

The browser only talks to the frontend. It proxies `/api/*` to the API (see `frontend/next.config.ts`), so the login cookie works.

## 1. Database (Neon)
1. Sign up at https://neon.tech and create a project.
2. Copy the connection string (`postgresql://...?sslmode=require`).

## 2. Push the code to GitHub
1. Create an **empty** repo at https://github.com/new (private is fine; don't add a README).
2. From the project folder:
   ```
   git remote add origin https://github.com/<github-username>/<repo>.git
   git push -u origin main
   ```

## 3. Deploy both services (Render Blueprint)
1. Sign up at https://render.com with GitHub.
2. Go to **New → Blueprint**, pick the repo, and click **Connect**. Render reads `render.yaml` and creates
   `automl-api` and `automl-studio-web`.
3. It asks for two values:
   - `DATABASE_URL`: the Neon connection string
   - `BACKEND_URL`: `https://automl-api.onrender.com`
4. Click **Apply**. The builds take about 5–10 minutes.
5. Open the `automl-api` service and check its URL at the top of the page.
   **If it isn't exactly `https://automl-api.onrender.com`** (Render adds a suffix when a name is taken):
   open `automl-studio-web` → **Environment** → set `BACKEND_URL` to the real URL → **Save, rebuild and deploy**.
6. Check that `https://<api-url>/api/health` shows `{"ok":true}`.
7. Open the `automl-studio-web` URL. That's the link you give to users.

`SECRET_KEY` is generated by Render. Colab notebooks get the API's public URL automatically (`RENDER_EXTERNAL_URL`).

## Updating later
`git push`. Render redeploys both services automatically.

## Free-tier limits
- Each service sleeps after 15 minutes without traffic. The next visit takes about a minute to wake it.
- Render's free CPU is small, so table training takes a few minutes. Slow models start unselected.
- Uploaded datasets and trained models are deleted when the API restarts or redeploys. Accounts, projects
  and all results stay in Neon. Users should download their model zip after training.
- Free instance hours are shared across a Render workspace each month. Sleeping services don't use them.
